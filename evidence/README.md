# Readable Execution Evidence

These Markdown files contain copied text output from real Databricks executions. They are intentionally committed as text because screenshots and source code alone do not prove that the build ran.

- `orchestration_run.md` — job and task results
- `governance_and_data.md` — UC objects, row counts, and metric outputs
- `genai_output.md` — real persisted `ai_gen` results
- `genie_agent.md` — real questions, generated SQL, and answers
- `lakebase_and_api.md` — synced-table status and live API responses

Evidence was captured from the synthetic FE Bar deployment in workspace `dbc-01f27b97-0e2e.cloud.databricks.com`.

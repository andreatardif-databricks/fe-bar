Quick start

  1. Pick an API key from the sidebar (or create one in Admin → API keys).
  2. Open Renewal health and click Try it.
  3. The request hits the same Lakebase mirror the production portal uses.

One integrated journey

Synthetic CRM, social, ad-spend, contract, and billing records land in governed Unity Catalog Volumes. Lakeflow incrementally produces Bronze, Silver, Gold, and Platinum tables. ai_gen persists campaign actions, Lakebase syncs operational serving tables, this app exposes them through FastAPI, and the curated Traackr Genie Agent answers business and API questions.

Decisions and trade-offs

DecisionWhyTrade-off
Lakebase for app servingSub-second operational reads without waking a warehouse.Requires an explicit sync after governed lakehouse processing.
Persist ai_gen outputsStable, auditable recommendations with no LLM call on page load.Recommendations refresh with orchestration, not continuously.
Genie over curated UC tablesGoverned natural-language analysis with inspectable SQL.Analytical questions use a SQL warehouse; operational APIs remain on Lakebase.
Synthetic dataSafe, reproducible demo with no customer information.Business-value numbers are explicitly illustrative until calibrated on production data.

Authentication

All /v1/brands/… endpoints require an API key in the X-Brand-API-Key header. Keys are scoped to a single brand and validated against public.api_keys in Lakebase on every request.

Example

curl -H "X-Brand-API-Key: pk_demo_coach" \
  https://<your-app-host>/v1/brands/ACC-00001/renewal-health

Errors

CodeWhen
401Missing or unknown key
403Revoked, expired, or key→brand mismatch
503Lakebase auth backend unreachable

GET /v1/brands/{brand_id}/renewal-health

Returns ARR, YTD attributed revenue, active-campaign count, and a derived 0–100 renewal-health score for one brand.

Path parameters

NameTypeRequiredDescription
